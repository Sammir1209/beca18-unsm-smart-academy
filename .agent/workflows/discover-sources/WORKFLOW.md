# Workflow 01: Discover Sources & Academic Ecosystem

## Objetivo
Escanear y catalogar fuentes oficiales para Beca 18 y UNSM, registrando prospectos, temarios, bases de concurso y exámenes de los últimos 3 años (2023, 2024, 2025).

## Pasos de Ejecución
1. Consultar portales institucionales oficiales:
   - PRONABEC: `pronabec.gob.pe`, resoluciones de Beca 18 y temarios ENP.
   - UNSM: `admision.unsm.edu.pe`, `unsm.edu.pe`, reglamentos y temarios de admisión.
2. Identificar y catalogar documentos descargables (PDFs, manuales del postulante).
3. Evaluar estado de accesibilidad de cada documento.
4. Generar o actualizar `research/sources/source-inventory.json`.
5. Si un examen requiere acceso manual protegido, emitir reporte de requerimiento al usuario.
