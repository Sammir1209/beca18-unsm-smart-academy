# Workflow 07: Build Materials & Summaries

## Objetivo
Elaborar guías de estudio, formularios resumidos, cuadros comparativos, esquemas de obras literarias y flashcards.

## Pasos de Ejecución
1. Agrupar temas por asignaturas clave (Aritmética, Álgebra, Física, Química, Biología, Historia, Lenguaje, etc.).
2. Crear guías compactas de consulta rápida y tablas sinópticas.
3. Generar mazo de flashcards asociadas para repetición espaciada.
4. Indexar en `data/materials/materials.json` y `data/flashcards/flashcards.json`.
