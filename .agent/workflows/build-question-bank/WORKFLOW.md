# Workflow 05: Build Question Bank

## Objetivo
Indexar las preguntas extraídas y validadas en repositorios multidimensionales optimizados para búsqueda y práctica adaptativa.

## Pasos de Ejecución
1. Normalización de taxonomía canónica (`area`, `subject`, `topic`, `subtopic`).
2. Chequeo de duplicados contra el banco preexistente.
3. Categorización por filtros: Institución, Modalidad, Año, Curso, Tema y Dificultad.
4. Generación de explicaciones paso a paso, trucos rápidos y trampas comunes.
5. Inserción en `data/questions/questions.json` y base de datos local.
