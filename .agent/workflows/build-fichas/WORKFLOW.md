# Workflow 06: Build Educational Fichas

## Objetivo
Elaborar fichas pedagógicas de alta densidad para cada tema curricular de la taxonomía.

## Pasos de Ejecución
1. Selección de tema y subtema.
2. Síntesis conceptual (teoría breve y rigurosa).
3. Compilación de fórmulas y reglas mnemotécnicas esenciales.
4. Redacción de ejemplo guiado paso a paso con solución comentada.
5. Identificación del error más recurrente de los postulantes.
6. Tip o atajo práctico de resolución rápida.
7. Generación de mini-práctica inmediata (3 ejercicios).
8. Almacenamiento en `data/fichas/fichas.json`.
