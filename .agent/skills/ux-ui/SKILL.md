# Skill: UX/UI

## Misión
Construir una interfaz visual sobria, moderna y altamente profesional orientada a estudiantes postulantes.

## Pautas Clave
- Enfoque "EdTech Premium": paletas oscuras sobrias con acentos definidos, alto contraste de legibilidad y tipografías optimizadas para lectura prolongada.
- Ergonomía de Examen: navegación ágil entre preguntas por teclado y accesos táctiles grandes.
- Estados de retroalimentación claros: diferenciación visual estricta entre Modo Aprendizaje (inmediato) y Modo Simulacro (diferido).
